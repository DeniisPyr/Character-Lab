Character Lab turns one picture of a character into a training-ready LoRA dataset: 16 consistent images in four kinds of shots, each checked and captioned. This page shows one real run, image for image. Nothing runs in your browser.

See the dataset Run it yourself

    The only input: one image of Diana.

    01 The reference

    Everything starts from one image

    1. Prepare. The image is checked and cropped to the character.
    2. Generate. Qwen-Image-Edit-2511 draws each shot from the reference. Later shots also see an earlier one, which keeps the outfit and face consistent.
    3. Check. A quality gate scores identity, face size and sharpness, and makes a failed image again with a new seed.
    4. Caption. Florence-2 describes each image. The caption starts with the trigger word and leaves out the fixed look, so the look binds to the trigger word.
    5. Export. Numbered image/caption pairs, ready for ai-toolkit or kohya.

    04 Run it yourself

    Your character, your dataset

    git clone https://github.com/DeniisPyr/Character-Lab.git
cd Character-Lab
python3 -m venv .venv && source .venv/bin/activate
pip install -e './backend[gpu]'
charlab generate reference.png --trigger diana

    Generation needs an NVIDIA GPU: 80 GB for the full model, or 24 GB in the quantized mode. The README has the details.
